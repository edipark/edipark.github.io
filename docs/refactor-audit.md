# 웹사이트 리팩토링 점검 — 2026-11-02

## 기준과 범위

현재 GitHub Pages 배포 경로(`.github/workflows/deploy-pages.yml`)를 기준으로
추적 중인 소스·설정·정적 파일 전체와 의존성, 로컬 빌드 산출물을 확인했다.
시작 시 작업 트리는 깨끗했다. 디자인·문구·링크·반응형 레이아웃·기존 동작은
유지하며, 서울대 로고의 중앙 정렬만 요청된 시각적 변경으로 취급했다.

## 조사 결과와 변경

| 영역 | 확인 결과 | 조치 |
| --- | --- | --- |
| 배포 | GitHub Actions가 Next.js로 `out/`을 생성해 GitHub Pages에 배포 | 기존 워크플로 유지. `build:pages`는 공통 `build` 명령의 호환 별칭으로 유지 |
| 개발·빌드 | 개발 명령은 vinext/Cloudflare, 실제 배포는 Next.js로 서로 달랐음 | 개발과 빌드를 Next.js/webpack으로 통일 |
| 서버·호스팅 | Worker, Vite 플러그인, `.openai/hosting.json`은 GitHub Pages 빌드에서 사용하지 않음 | 해당 대체 배포 체계 제거. 외부 호스팅 계정에는 변경 없음 |
| DB·인증 | 빈 Drizzle 스키마, D1 메모 예제, ChatGPT 인증 함수가 페이지에서 참조되지 않음 | 관련 소스·예제·설정·명령 제거 |
| 의존성 | 대체 빌드 체계와 DB 때문에 불필요한 직접 의존성 9개가 남아 있었음 | 제거 후 잠금 파일 갱신. 남은 패키지의 버전 변경 없음 |
| 페이지 | 영상만 사용하는데 이미지/영상 분기와 미사용 poster 옵션이 존재 | 실제 영상 마크업으로 단순화. 프로젝트 데이터와 관심 분야를 `app/portfolio-data.ts`로 분리 |

| 서울대 로고 | 204×240 캔버스에서 도형의 상단 여백 11px, 하단 16px | 도형을 원본 크기로 2px 아래 이동해 여백 13px/14px로 조정. 도형 픽셀·색상·캔버스 크기 동일 |
| 스타일 | Tailwind 유틸리티는 사용하지 않지만 기본 reset/preflight가 실제 렌더링에 적용됨 | Tailwind와 `app/globals.css` 유지. 제거 시 생길 수 있는 렌더링 변경 방지 |
| 다크 모드 | 시스템 설정과 저장된 사용자 선택을 각각 지원 | 두 경로 및 첫 렌더링 테마 스크립트 유지 |

잠금 파일 패키지 항목은 **709 → 435**, 파일 크기는 **380,125 → 231,901 bytes**로
줄었다. 이는 의존성 구성 수치이며, 브라우저 전송량이나 실행 속도의 측정치는 아니다.

## 검증

- 수정 전에 production build를 실행해 실제 출력의 `<main>` 전체, CSS,
  사용 중인 정적 파일, 테마·확대 창·루트 레이아웃 소스를 기준으로 저장했다.
- `tests/render-equivalence.test.mjs`는 변경 전후 `<main>`이 문자열 단위로
  동일함을 확인한다. 이미지 크기·순서·속성·문구·다이얼로그 ID도 비교 대상이다.
- 스타일 원본은 변경하지 않았다. 빌드된 CSS도 비교하되, Tailwind가 소스의
  일반 단어에서 생성한 **미사용** 유틸리티 레이어만 제외한다. 제외하는 클래스가
  출력 HTML에 사용되면 테스트가 실패한다. 모바일·다크 모드 규칙도 비교에 포함된다.
- 서울대 로고 외의 사용 중인 정적 파일과 세 인터랙션/레이아웃 소스는 SHA-256으로
  동일성을 검사한다. 서울대 로고는 별도 픽셀 검사로 도형 자체의 동일성과
  투명 여백 중앙 정렬을 확인했다.
- `npm test`의 production build 및 5개 검사, `npm run lint`,
  `npm run typecheck`, `git diff --check`를 실행했다.

이 검증은 production HTML·CSS·자산 비교이며 브라우저 스크린샷 픽셀 비교는 아니다.
새 디자인 변경을 할 때에는 기준 파일을 자동 갱신하지 말고 의도된 차이를 검토해야 한다.
현재 변경은 로컬 작업 트리에 있으며 커밋·푸시·배포는 수행하지 않았다.
