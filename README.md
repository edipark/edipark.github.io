# edipark.github.io

Sunghyun Park's personal portfolio, built with Next.js and vinext.

## Local development

```bash
npm install
npm run dev
```

Edit the portfolio content in `app/page.tsx` and the visual system in
`app/globals.css`.

## Deployment

Pushes to `main` are exported as a static site and deployed automatically to
[edipark.github.io](https://edipark.github.io/) with GitHub Pages.
